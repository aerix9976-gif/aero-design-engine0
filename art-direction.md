# Art Direction Without Generic UI

## Use this skill when

New marketing pages, portfolios, product landing pages, or visual redesigns where a recognizable aesthetic matters.

## Prerequisites
- Know the subject, primary audience, one page goal, and existing brand constraints.
- Read current design tokens and brand guidance before proposing replacements.

## Workflow
1. Write a one-sentence visual thesis anchored to the product's world, audience, and content.
2. Explore at least two compositions that differ structurally—not only in accent color. Compare content order, image strategy, type character, density, and signature motif.
3. Choose 4–6 semantic colors, display/body/utility type roles, spacing rhythm, and one memorable signature detail. Explain why each choice fits.
4. Compose the hero around the strongest truthful proof: product interface, concrete benefit, relevant visual, or a sharply stated idea.
5. Build a complete page with realistic content, responsive sections, accessible controls, and a consistent token system.
6. Run a visual critique pass: remove unearned gradients, random labels, redundant cards, generic stock-like imagery, and any element that does not help comprehension or identity.

## Hard rules
- Do not choose a trendy style just because it is familiar to the model.
- Do not ban stylistic tools universally; evaluate whether each belongs to this specific brief.
- Do not fabricate product screenshots, metrics, customer logos, reviews, or outcomes.
- One strong signature element is usually better than many competing effects.

## Acceptance criteria
- [ ] The intended audience and primary action are clear at first glance.
- [ ] The chosen visual direction has a concise rationale tied to the actual brief.
- [ ] Typography, composition and content remain coherent at narrow widths.
- [ ] The result includes visible focus, keyboard support, semantic controls, and a reduced-motion path.
